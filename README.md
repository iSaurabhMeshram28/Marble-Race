# Marble-Race

Marble-Race is an interactive and immersive 3D marble racing game. Built with modern web technologies like **React Three Fiber**, **React Drei**, and **React Rapier**, the project demonstrates a blend of advanced physics simulation and 3D rendering.

## Features
- **3D Marble Racing**: Realistic simulations with physics-based interactions.
- **Advanced Rendering**: Beautiful 3D graphics powered by React Three Fiber.
- **Physics Engine**: Robust collision detection and physics simulation using React Rapier.

## Technologies Used
- **React Three Fiber**: For 3D rendering and scene management.
- **React Drei**: For helpful utilities and prebuilt 3D components.
- **React Rapier**: For realistic physics simulations.
- **JavaScript, HTML, CSS**: For additional game logic, structure, and styling.

## Getting Started
To run the project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/iSaurabhMeshram28/Marble-Race.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Marble-Race
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open your browser and navigate to `http://localhost:3000` to view the game.
